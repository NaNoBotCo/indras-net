# Indra's Net, Drawn

A plain-spoken 'splainer of Indra's Net — the old picture of a net with a jewel at every knot, each
jewel showin' all the others — read sixteen ways, and drawn from the math of mirrors.

**Live:** https://nanobotco.github.io/indras-net/

- `tools/figures.py` — the still pictures and every number the pages quote (`build/facts.json`)
- `js/net.js` — the moving pictures: the jewel net, Fazang's mirror room, round mirrors, the small world
- `tools/site.py` — the pages · `tools/card.py` — the share card
- `indras_net.py` — the math in one file, nothing to install
- `./publish.sh` — build, check, copy to `docs/` (GitHub Pages serves `main` `/docs`)
